# FAMILY実画像の暫定ラベル確認

これは200枚確認時点の途中記録です。その後の[全体探索・実画像学習の結果](real-v2-experiment.md)を参照してください。

2026-11-08。**実データ3分類モデルの学習には未到達です。archの採用可能な暫定ラベルが不足しています。**

配布1,500枚のうち200枚を一覧で実際に視認し、うち21枚を512×512の個別画像で再確認しました。最初の60枚に、別40家族から120枚を追加。さらに境界候補のある3家族の別指20枚を調べました。この選び方は分類候補探索のためで、無作為な性能評価標本ではありません。

| 状態 | 枚数 |
| --- | ---: |
| arch 暫定採用 | 0 |
| loop 暫定採用 | 3 |
| whorl 暫定採用 | 7 |
| 保留 | 190 |

ラベルは **Astraによる単独AI視覚レビュー**。人による確認済み正解、専門家判定、2人の合意ではありません。画像ごとの観察根拠、レビュアーID、品質/模様範囲、出典、家族フォルダ単位の保守的groupをローカルCSVへ記録しました。亜型の細かな判定は行わず、分類構造が曖昧なものは保留しました。保留190枚すべてが利用不能と確定したわけではありません。

arch候補5件を原寸確認しましたが、tented archとloopの境界、薄さ、下端の模様範囲不足が残りました。見えないdeltaを不存在と扱ったり、不足クラスを埋めるためにarchへ割り当てたりしていません。**残り1,300枚は未調査であり、このデータセットにarchがないという結論ではありません。**

暫定ラベルCSVを `export --allow-provisional` に渡し、実際に `all_classes_required_in_train` で拒否されることを確認。学習manifest・実データ重みは作成されていません。家族をまたがない予定splitは記録しましたが、評価は未実施です。既存の合成モデルの重み・100%という合成実験値は変更しておらず、実指性能として利用できません。

## 次に確認するもの

ローカルの `fingerprint_model/local/family-visual-review-v1/review.html` に、arch境界候補5件→暫定ラベル10件→その他保留の順で表示します。個人ファイル名・画像・レビュー生データは公開レポートへ含めていません。`label-shortage-report.json` に実行結果を保存しています。

まず境界候補を人が再確認し、必要なら未確認画像を追加探索します。学習/validation/testへ分けられる少なくとも3つの独立家族のarch例が必要ですが、3例だけで実用的な学習量になるわけではありません。十分なラベルが揃ったら暫定実験として学習し、別家族で評価します。スマホ指写真の評価には、別途同じ撮影枠から得たデータが必要です。
