# 合成3分類の実験結果

実施日：2026年11月8日。**実指写真の学習・評価は0枚です。以下は合成形状の基準実験で、実指紋の分類精度ではありません。**

## データと目視確認

`procedural-motif-v1` で各クラス120基底模様、各4変種、合計1,440枚を生成。データseedは20261108。光・コントラスト・ノイズ・小回転の分布をクラス間で揃え、クラス名やIDは分類器の入力に含めません。

[一覧画像](synthetic-contact-sheet.png)を実際に表示して確認しました。archは左右に続く山形、loopは閉じないU状の曲線、whorlは閉じた同心輪になっています。ただしloopは理想化した形状で、デルタや本物の隆線構造を再現する医学的・法科学的な生成器ではありません。これらの3つの数式を区別できることが、本実験の到達点です。

| 分割 | 基底模様グループ数 | 画像数 |
| --- | ---: | ---: |
| train | 252 | 1,008 |
| validation | 54 | 216 |
| test | 54 | 216 |

変種生成前に基底模様単位で分割しました。同じgroup_idの分割重複はなく、分割をまたぐ同一の正規化画素も検査しました。これは実在人物の分割ではなく、**合成基底模様の分割**です。近似模様は共通の数式族に由来するため、実写真のdomain差を検証したものではありません。

## 学習と評価

Python 3.12.14 / NumPy 2.3.5 / Pillow 13.0.0、CPU。512次元方向場→3クラス線形softmax。300 epoch、学習seed42、学習率0.08、L2=0.002。訓練平均・標準偏差で正規化し、validationの交差エントロピーが最小のepochを採用。testはその後に評価しています。

採用されたのはepoch 1（validation loss約0.00001553）でした。強制3択のtest accuracy=1.0、macro-F1=1.0。最初の更新で区別できるほど単純な生成規則のため、結果は高く出やすく、実指写真への一般化や高精度を示しません。

混同行列（行=正解、列=予測）：

| 正解＼予測 | arch | loop | whorl |
| --- | ---: | ---: | ---: |
| arch | 72 | 0 | 0 |
| loop | 0 | 72 | 0 |
| whorl | 0 | 0 | 72 |

暫定拒否を含めると216枚中204枚を採用、12枚をunknown、coverage=94.44%。採用分のaccuracy=1.0。スコアしきい値は約0.999935で、validationで正解した例の下位5%点と下限0.55から決めました。さらに予測クラスの訓練中心からの距離をvalidationで設定した半径と比較しています。**この極めて高いスコア値は精度保証でも校正済み確率でもありません。** しきい値は実写には適合確認していません。

詳細なepoch、版、manifestハッシュ、分割数、拒否結果は[metrics JSON](synthetic-metrics.json)に記録しています。品質しきい値やOOD失敗率についての実指ベンチマークは行っていません。
