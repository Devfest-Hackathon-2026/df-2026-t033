# 同梱参考モデル pattern-v1

`templates.npz` は実画像の方向場テンプレート135個（27枚×元画像と4変種）を含みます。元画像そのもの・個人名・画像パス・写真は含みませんが、生体由来の方向特徴を含むデータ派生物です。SHA256.txtで配布ファイルを検査します。

## 帰属表示・利用条件

Diptadip Maiti, Debashis Das (2023), **FAMILY FINGERPRINT DATASET**, Version 1, Mendeley Data, DOI [10.17632/m4kz5ygxrn.1](https://doi.org/10.17632/m4kz5ygxrn.1)。[公式配布](https://data.mendeley.com/datasets/m4kz5ygxrn/1)、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。原著者が本プロジェクトを支持する意味ではありません。

この同梱モデルは上記データの派生物として **CC BY 4.0** で提供します。再配布時は本カードの出典・ライセンスリンク・変更内容を維持してください。リポジトリのコードはMITであり、モデルの条件と区別します。下流で変更した場合はその変更も表示してください。

加工：単独AIによる暫定形態ラベルを用い、コントラスト・背景・方向場の処理と少角回転・移動を行いテンプレート化しました。旧test5枚は含みません。元スキャン画像・個別注釈は非同梱。スマホ開発写真2枚は学習していません。

## 制約

用途は音楽向けarch / loop / whorlの参考候補。本人認証・照合用ではありません。開発27枚で14一致、arch0/4。専門家正解でなく単独AIの暫定ラベル、方法選択に使った開発評価です。スマホ写真の正解率・他人や撮影条件への一般化は未検証です。候補は常に要レビューで確定ラベルではありません。

モデル変更時は新しい版のディレクトリを作り、SHAとモデルカードを更新してください。
