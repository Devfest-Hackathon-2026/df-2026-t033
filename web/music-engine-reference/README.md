# Fingerprint Symphony Studio v3

ブラウザ内で指紋の測定データから作曲する静的Webアプリ。

## 起動
`python3 -m http.server 8080 --directory dist`

## 作曲ルール
- BPM = 隆線数 × 2.5。丸め・テンポ上限への補正は行わない。入力は1〜400の整数。
- 弓状 arch → ヒップホップ（スウィング、柔らかい旋律、疎なベース）
- 蹄状 loop → ハウス（ストレート、プラック、拍ごとのベース）
- 渦状 whorl → テクノ（16分シーケンス、倍音のあるシンセ、細かいベース）
- 特徴点 ending（端点）→ kick（バスドラム）、bifurcation（分岐）→ snare、dot / other → hi-hat。全て合成音。
- 座標xを16ステップの1小節に量子化、yで音量を変化。ヒップホップのみ裏16分にスウィングを付加。各特徴点のドラムは毎小節反復、重複座標も別イベントとして含める。
- 共同曲：平均隆線数 × 2.5 を共通BPMにし、表示順で最初の参加者の指紋種類でジャンルを決定。全員の特徴点ビート・旋律を同じグリッドへ統合。各人のBPMはカードに表示。
- 個人曲8秒〜、共同曲20秒〜。低BPMで1小節が収まらないときは1小節分まで延長（最大96秒）。

## 入力JSON
```json
{
  "candidate": "whorl",
  "ridge_count": 48,
  "minutiae": [
    {"type":"ending", "x":0, "y":0.4},
    {"type":"bifurcation", "x":0.25, "y":0.5},
    {"type":"dot", "x":0.125, "y":0.2}
  ]
}
```
minutiaeは1〜512点、x/yは0〜1。ピクセル座標の場合は画像の幅・高さで正規化して渡す。種類は candidate または pattern に arch / loop / whorl。
旧fingerprint_modelのpredict出力にdecisionがある場合はreference_candidate、qualityがある場合はreadable=trueが必要。旧出力には隆線数と特徴点が含まれないため手入力で補う。

## 写真 → 自動解析 → 自動作曲
同意後にJPEG/PNG/WebP（最大10MB、各辺192〜8192px）を選ぶとWorkerで端末内解析。種類・隆線数・特徴点を手入力する必要はなく、個人曲のPCMを自動生成し再生可能にする。音声再生は明示的な再生ボタンから。

処理：384pxアスペクト比保持縮小 → 局所照明補正 → ブロック勾配による方向・コヒーレンス → 最大連結領域 → 手続き的なarch/loop/whorl方向テンプレートとの比較 → 二値化 → Zhang–Suen細線化 → crossing numberによる端点/分岐と小さい独立線による点状候補。近接する偽特徴候補と画像・領域境界の候補を除外。

隆線数は局所の勾配方向に沿った中心付近5本の走査線との隆線交差数の中央値。**コア・デルタ間の法医学的なridge countではない**。撮影範囲・向き・ピント・解像度でBPMも変わる。自動判定は学習済み分類モデルではなく、独立実装した画像ヒューリスティック。実写真での精度未検証。参考推定と常時表示し、特徴点・走査線・ばらつきの警告を可視化。

暗い/明るすぎる/低コントラスト/有効領域不足/平行線だけ/分類適合不足/隆線交差計測不足は撮り直しを表示し、曲を生成しない。種類の候補が近接する場合は最上位の候補から作曲したことを通知。特徴点が0の場合はその旨を表示し、架空の点は作らず特徴点ドラムなしで旋律とベースを生成する。点状候補はノイズの可能性もある。

解析は30秒タイムアウト、入力画面を閉じる/セッション終了/ページ離脱でWorkerを停止。古い解析結果の参加者登録や曲の生成を拒否。


## 保持
入力は端末内処理のみ、外部送信・永続保存なし。参加者削除で関連曲も破棄。終了/30分無操作/ページ離脱でセッションを破棄。保存済みWAVは端末に残る。Google Fontsへの通信に入力を含めない。

## 検証
`node test-analysis.cjs`：3種類×3回転の手続き的合成模様から解析→作曲→音源まで、不良入力、既知の端点・分岐・点状候補、細線化を検証。これらは実写真の精度評価ではない。

`node test.cjs`：BPMの正確性・小数・境界値、3ジャンル、特徴点のドラム対応、座標とスウィング、共同曲の平均BPM・主ジャンル、低BPMの全特徴点収録、WAV、不正入力。
