## 修正した点

1. ファイル選択用 `<input type=file>` を `display:none` から視覚的に隠す方式へ変更し、モバイルのファイル選択操作との互換性を改善。
2. フロントのAPI送信処理で、HTTP 502/503/504や不正なJSON応答を分かりやすく扱うよう修正。
3. 撮影後にサーバーへ送信する仕様に合わせて、カメラ画面のプライバシー説明を修正。
4. 過去版の説明に残っていた「サーバー送信なし」「実測の指紋解析なし」などの矛盾を更新。
5. Windows用の起動BATファイルを追加。API・画面を別々のターミナルで起動できるようにした。

## 開発者向けの追加テスト

`python tests/run_node_smoke.py` でローカルのFastAPIを立て、同梱の合成画像を送信します。前提：Python、Node.js 22以上、FastAPI依存関係をインストール済み。

## 実PCで必ず行う操作テスト

1. `start_backend.bat` と `start_frontend.bat` を起動する。
2. `http://localhost:5173` を開き、「この端末で作る」→人数を選択→次へ。
3. 参加者Aの同意チェック→「画像をアップロード」→JPEG/PNG/WebPを選択する。
4. 「画像をサーバーで確認しています…」が消え、プレビューとファイル名が表示されることを確認する。
5. 続いて個人曲生成まで進む。失敗した場合は画面のエラーを確認する。
6. 指紋登録済みのAを完全削除するとプレビュー・関連曲が消えることを確認する。
7. カメラ撮影→写真確認→「この画像を登録」でも同様に登録できることを確認する（HTTPSまたはlocalhostが必要）。
8. バックエンドを停止してから登録を試し、成功と誤表示されず接続エラーになることを確認する。
