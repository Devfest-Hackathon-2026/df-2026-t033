# 画面・機能の現状（v14 統合版＋画像API）

- ホーム：「この端末で作る」「友達と作る」「ランダムで作る」などの画面。
- 1台で作る：1〜3人、指紋登録、個人曲生成、2〜3人の共同曲生成。
- 指紋撮影：カメラ・中央ガイド・撮影後の確認・撮り直し。ファイルからのアップロードも可能。
- 画像登録：本人の同意がある場合だけFastAPIへ一時送信して形式等を検証。正常受付後に画面内で登録。
- 指紋解析と作曲：JavaScriptがブラウザ内で実行。指紋の種類によってジャンルを自動決定。特徴抽出の実写精度は未検証。
- 音源：ブラウザ内でWAVを生成し、再生/停止。サーバーには送らない。
- 曲一覧・参加者：ページ内のReact stateで保持、完全削除・終了時に解除（恒久保存なし）。
- 友達と作る・ランダムで作る：現在はUIのみで通信・マッチングは未実装。
- 設定：テーマカラー等を扱う。テーマのみブラウザのlocalStorageで保持。

## ソースの主な位置

- `frontend/src/App.jsx` ：画面と登録・生成の制御。
- `frontend/src/api.js` ：画像検証APIへの送信。
- `frontend/public/analysis-worker.js`, `frontend/public/fingerprint.js` ：指紋解析。
- `frontend/src/lib/music.js` ：作曲・WAV生成。
- `frontend/vite.config.js` ：ローカル開発用APIプロキシ。
- `backend/main.py` ：最小画像受付API。
