# 課題・技術選定の記録

2026年11月6日、題材をFingerprint Symphonyとして要件を整理しました。技術スタックは未確定です。[要件定義](07-requirements.md)は検討版で、MVPの操作方式・データ保持・生成方式・評価基準には合意が必要です。今回は文書のみを作成します。個人情報や非公開URLは記録しません。

## 課題の整理

| 項目 | 記入欄 |
| --- | --- |
| 想定する利用者 | 音楽経験がなくても共同創作を楽しみたい参加者 |
| 解決したい困りごと | 音楽づくりへの参加の難しさと、他の参加者と交流するきっかけの不足（仮説） |
| 困りごとの根拠 | 企画仮説。利用者調査・交流効果は未検証 |
| 提供したい体験・価値 | 指紋画像の視覚特徴を個人曲にし、参加者を組み替えて共同曲の変化を楽しむ |
| 最小限の完成条件 | 撮影/アップロード、特徴抽出、個人曲、2〜3人曲、再生、参加者変更。詳細は要件定義のF01〜F11 |
| 今回扱わない範囲 | 本人識別・認証。保存共有・複数端末・リアルタイムDJは今回の必須外 |
| 審査・必須要件との対応 | Google指定実行基盤・Google技術の中核利用・選定理由・著作物記録。具体的な対応はG2で確認 |
